# 안심클린 매니저 운영 정책 (구현 기준 문서)

> 사용자 승인 2026-09-22. 매니저에게 보여 줄 원본은 `~/Desktop/안심클린-매니저-정책.md` 와 같다.
> 코드에서 이 문서를 가리키는 곳: `profile/ManagerPenaltyService`·`ManagerPenalty`·`ManagerPenaltyCleaner`,
> `job/JobService.cancelByManager`·`recordTardy`, `booking/StaleBookingCleaner`(미방문), `V022__manager_penalty.sql`.


**시행일**: 2026년 9월 22일 · **버전** 1.0 · **적용 대상**: 안심클린 청소 매니저 전원

이 문서는 매니저가 수락한 방문을 지키지 못했을 때의 기준을 정합니다.
목적은 벌을 주는 것이 아니라 **고객이 기다리다 하루를 버리는 일을 막는 것**입니다.
그래서 "일찍 알려주면 불이익이 없고, 늦게 알릴수록 책임이 커지는" 구조로 만들었습니다.

---

## 1. 방문 취소

수락한 방문을 못 가게 되면 **앱에서 바로 취소**해주세요. 고객에게 즉시 알림이 가고, 서비스가 다른 매니저를 찾습니다.

| 언제 취소하나 | 방법 | 패널티 | 고객에게 일어나는 일 |
|---|---|---|---|
| **방문 24시간 전까지** | 앱 › 업무 상세 › 방문 취소 | **월 2회까지 0점**<br>3회째부터 1점 | 즉시 알림 + 자동 재매칭 |
| **24시간 ~ 4시간 전** | 앱 › 업무 상세 › 방문 취소 (사유 필수) | **1점** | 즉시 알림 + 재매칭 + 사과 쿠폰 |
| **4시간 이내 · 미방문** | 앱에서 불가 → **고객센터 전화** | **3점** + 해당 건 정산 없음 | 즉시 알림 + 쿠폰 + 고객센터 유선 안내 |

- **취소 사유**: 질병·부상 / 교통사고·차량 문제 / 장비 고장 / 개인 사정 / 기타(직접 입력)
- 취소해도 **고객의 예약은 사라지지 않습니다.** 다른 매니저를 찾는 상태로 돌아갑니다.
- 취소한 방문은 **같은 매니저에게 다시 배정되지 않습니다.**

### 증빙이 있으면 면제
진단서, 사고 확인서, 천재지변 등 어쩔 수 없는 사유는 **접수 후 7일 안에** 고객센터로 증빙을 보내주시면 점수를 면제합니다.
면제해도 기록 자체는 남지만 점수에는 반영되지 않습니다. 면제로 점수가 정지 기준(5점) 아래가 되면 **걸려 있던 콜 배정 정지도 풀립니다.**

## 2. 지각

약속 시간에서 **30분을 넘겨 청소를 시작하면 0.5점**이 기록되고, 고객에게 자동으로 알림이 갑니다.
길이 막히거나 앞 일정이 늦어지면 **미리 고객에게 연락**해주세요.

---

## 3. 누적 점수와 조치

점수는 **최근 12개월** 것만 셉니다.

| 누적 점수 | 조치 |
|---|---|
| **3점** | 경고 알림 |
| **5점** | **콜 배정 7일 정지** |
| **8점** | **콜 배정 30일 정지** + 재교육 이수 |
| **10점** | 계약 유지 여부 심사 |

- 정지 기간에는 새 콜을 받지 못합니다(정지 전에 받아 두고 아직 수락하지 않은 콜도 닫힙니다). **이미 수락한 방문은 그대로 진행**해주세요.
- 앱 **MY › 패널티 내역**에서 지금 점수와 이력, 다음 단계를 언제든 볼 수 있습니다.

### 점수 회복
**3개월 동안 아무 일도 없으면 1점이 줄어듭니다.** (남은 점수가 1점보다 적으면 남은 만큼만 — 회복이 쌓여 다음 점수를 미리 깎지는 않습니다.) 모든 점수는 12개월이 지나면 자동으로 사라집니다.

---

## 4. 정기청소를 맡은 경우

정기청소는 **매월 같은 날짜에 한 번씩, 6개월(6회)** 방문하는 상품입니다.
같은 매니저가 계속 가는 것이 고객에게 가장 좋기 때문에, 서비스는 **직전 회차를 맡은 매니저에게 다음 회차를 먼저** 제안합니다.

한 회차라도 취소하면 **그 고객의 다음 회차 우선 제안에서 빠집니다.** (일반 콜로는 계속 받을 수 있습니다.)

---

## 5. 장비(안심캠) 문제로 못 가게 되면

바디캠이 없으면 청소를 시작할 수 없습니다. 현장에서 장비가 고장 났다면:

1. 앱 › 청소 준비 화면의 **카메라 다시 연결**을 먼저 눌러보세요
2. 그래도 안 되면 **고객센터로 바로 전화**해주세요 (방문 시간이 임박했다면 문의 접수보다 전화가 빠릅니다)
3. 고객센터가 고객에게 안내하고 일정을 조정합니다

장비 고장으로 확인되면 **취소 점수는 면제**됩니다.

## 6. 자주 묻는 질문

**Q. 아파서 못 가는데 오늘 방문이에요.**
A. 4시간 이내라 앱에서는 취소할 수 없습니다. 고객센터로 전화해주세요. 진단서를 보내주시면 점수는 면제됩니다.

**Q. 고객이 갑자기 취소했는데 제 점수가 올라가나요?**
A. 아니요. 고객이 취소한 건은 매니저 기록에 남지 않습니다.

**Q. 정지 중인데 이미 잡힌 방문은요?**
A. 그대로 진행해주세요. 정지는 **새 콜을 받는 것**만 막습니다.

**Q. 점수를 어디서 보나요?**
A. 앱 **MY › 패널티 내역**입니다. 누적 점수, 다음 단계, 지난 기록이 모두 있습니다.

## 부록 · 운영 기준값

아래 숫자는 서버 설정(`app_settings.manager_penalty`)으로 관리하며, 바꾸면 앱에도 즉시 반영됩니다.

| 항목 | 값 |
|---|---|
| 무료 취소 (24시간 전) | 월 2회 |
| 24시간 전 취소 (한도 초과) | 1점 |
| 24~4시간 전 취소 | 1점 |
| 미방문 | 3점 |
| 지각 (30분 초과) | 0.5점 |
| 앱 취소 마감 | 방문 4시간 전 |
| 점수 유효 기간 | 12개월 |
| 무사고 회복 | 3개월마다 1점 |
| 정지 기준 | 5점 = 7일 · 8점 = 30일 |
| 심사 기준 | 10점 |

**아직 결정되지 않은 것**
- 고객 사과 쿠폰: 결제(PG) 연동 후에 발급됩니다. 지금은 알림만 나갑니다.
- 고객센터 전화번호: 운영 번호가 정해지면 앱에 "고객센터 전화하기" 버튼이 나타납니다.
